Multi-talker ASR with LLMs — Model Structure & Training/Decoding Loops

Companion to WORKFLOW.html / CODE_GUIDE.html. Everything below was cross-checked against the source on branch v1.0 after the REVIEW.md fixes; each box names the file that implements it. Default numbers assume wavlm-large (hidden 1024, adapter ×3 stride-2 convs) and a LLaMA decoder.

Legend: trainable typically updated; frozen frozen by default (freeze_model + unfreeze_selected_params, controlled by train_mode and the partial_*_unfreeze flags); LoRA low-rank adapters; optional only present for certain flags. Dashed boxes are optional modules.

1 · Model structure (forward path)

Input waveform (B, Tsamples) @ 16 kHz + attention_mask (B, Tsamples) from the feature-extractor pad
▼
WavLM conv feature encoder frozen → (B, T, 1024)   T ≈ Tsamples/320 (20 ms hop) models/modeling_wavlm.py · frozen via freeze_feature_encoder=true
▼
WavLM transformer (24 layers) frozenif encoder_freeze=false → (B, T, 1024) = encoder_outputs[1] “pre-adapter” this tensor feeds the SEPARATOR/CTC branch and the cross-attn memory
▼ (main AED path)
WavLM adapter trainable 3 × (Conv1d stride 2 + GLU) → (B, T′, 1024), T′ = T/8 = encoder_outputs[0] · unfrozen by name match “adapter”
▼
enc_to_dec_proj trainable Linear 1024 → dmodel → (B, T′, dmodel) modeling_speech_encoder_decoder_llama.py · unfrozen via partial_others_unfreeze="enc_to_dec_proj"
▼ speech embeddings, inserted INSIDE the decoder
▼ (only when talker_ctc=true)
Separator trainableoptional Linear 1024→h → custom LSTM ×2 → N branches → N × (B, T, 1024) models/separator.py · h = separator_hidden
▼
serialized_ctc[i], i = 1…N trainable Linear 1024 → V+1   (blank id = V = decoder.vocab_size) models/ctc.py · one head per speaker · input lengths from _get_feature_vector_attention_mask_x0 (pre-adapter T)
▼ CTC loss / CTC greedy decode / optional refiner & bridge
LLaMA decoder base frozenself-attn LoRA layers: self-attn (k/q/v/o ± PEFT LoRA) → [cross-attn adapter] → MLP models/modeling_llama.py + models/llama_modules.py · speech embeddings are concatenated into the hidden states in LlamaModel.forward (see §2) · lm_head/embed_tokens unfrozen via partial_decoder_unfreeze
Per-layer cross-attention adapter optionaladapgatetiny: rank-gated LoRA Q = htext, K/V = memory; memory = mix (B,T,1024) or sep (B,N·T,1024) tiny / gatetiny / adapgatetiny / ctcaware — one module per decoder layer, applied after self-attention (decoder_cross_attention* flags)
HybridLoss L = α·CE(logits, labels) + (1−α)·meani CTCi models/losses.py · α = ctc_alpha (default 0.7) · train_mode ∈ {attention, ctc, hybrid} selects active terms · CE ignore_index = −100 · fixed-order CTC (head i ↔ speaker i, no PIT)

Two independent LoRA groups (do not conflate)

Self-attention LoRACross-attention LoRA
Where PEFT-injected into decoder k/q/v/o_proj (src/insert_adapter_decoder.py, when adapter_only_decoder=true) inside the adapgatetiny cross-attn adapter (models/adap_gate_tiny_crossatt_module.py)
Hyper-params selfattn_lora_r / selfattn_lora_alpha / selfattn_lora_dropout r_max / lora_alpha (rank-gated, prunable)
After training saved as model_unmerge.safetensors, then merged into plain weights by utils/merge_adapter.py --lora_r --lora_alpha → model.safetensors kept as-is in the checkpoint (own parameter names)

2 · Token / label layout (the part worth confirming carefully)

The collator (src/data_collator.py) builds decoder_input_ids and labels; the model only prepends speech_len × (−100) to labels to re-align after the speech insertion. CE is computed without an extra shift — logits[t] is compared to labels[t] directly.

Non-instruct mode (speech inserted right after BOS)

# tokens l1..lA = speaker-1, l(A+1)..lL = speaker-2, joined by <sc>; S = speech_len (T′)
decoder_input_ids : [BOS]  l1 l2 … <sc> … lL          (length L+1; full labels, ISSUE-06 fix)
embeddings        : [BOS]  [speech ×S]  l1 l2 … lL   (insertion in LlamaModel.forward)
labels            : [−100 ×S]  l1 l2 … lL EOS −100…  (EOS at first pad; −100 = ignored)
                     ↑ last speech frame predicts l1; li predicts l(i+1); lL predicts EOS

Instruct mode (speech inserted between <bos_speech> and <eos_speech>)

prompt_ids        : <bos_prompt> p1 … pK <eos_prompt> <bos_speech> <eos_speech> <bos_response>
decoder_input_ids : [BOS] prompt_ids r1 … rL                       (r* = serialized response)
embeddings        : [BOS] … <bos_speech> [speech ×S] <eos_speech> <bos_response> r1 … rL
labels            : [−100 ×S] [−100 × prompt_token_len] r1 … rL EOS −100…
                     prompt prefix masked per-sample via prompt_token_len (collator)

Batch-uniformity assumption (ISSUE-07): the <bos_speech>/<eos_speech>/<bos_response> positions are taken from batch row 0 and applied to all rows. This is valid because the dataset uses ONE constant prompt; the code now raises a clear error if a batch ever violates it.

Per-speaker CTC labels

# split from decoder_input_ids (utils/split_labels_by_sc.py), NOT from labels:
non-instruct : take decoder_input_ids[:, 1:]               # drop [BOS]
instruct     : take everything after <bos_response>        # <eos_response> → pad first
then         : split at <sc> into exactly N segments  → (label_i, len_i) per speaker
CTC_i        = CTCLoss(log_softmax(ctc_lo_i(sep_i)), label_i, hlens, len_i)   # blank = V

3 · Training loop (run.sh stage 3)

Per-run setup (finetune_asr.py)

1  parse args (src/arguments.py)
2  resume_or_raise()        # auto-resume if ckpt exists
3  load DatasetDict          (datasets/<corpus>)
4  load config + copy model flags onto it
5  load FE / tokenizer / AED model (dump/…)
6  [optional] load_sep_ctc_from_partial()
7  freeze_model → insert self-attn LoRA
   → unfreeze_selected_params(train_mode, …)
8  maybe_resample_dataset (→16 kHz)
9  preprocess_and_filter:
     audio → input_values, len filter,
     text  → labels, prompt_ids, prompt_token_len
10 collator + Seq2SeqTrainer
   (remove_unused_columns=False, ISSUE-01)
11 trainer.train()
12 save: ctc / full-finetune → model.safetensors
        LoRA → model_unmerge.safetensors
        → merge_adapter (r, α) → model.safetensors
        → fix_safetensors_metadata

Per-step loop (src/trainer_seq2seq.py)

for batch in dataloader:                # DDP, group_by_length
  batch = collator(features)           # §2 layout
  out   = model(inputs=input_values,
                attention_mask,        # audio mask
                decoder_input_ids,
                labels, prompt_ids)
        # forward: encoder → [separator→CTC] →
        #          decoder(+speech insertion) → HybridLoss
  [PCGrad on encoder/separator grads]  # NOTE: silently
                                       # inactive under DDP — ISSUE-10,
                                       # needs author decision
  accelerator.backward(loss); clip; step

every eval_steps:
  evaluate() — loss + (predict_with_generate)
  greedy generate → WER                # prompt words leak into
                                       # eval_wer (ISSUE-17, monitoring only;
                                       # best model uses eval_loss)
every save_steps: checkpoint (save_total_limit=5)

4 · Decoding loops

Attention (AED) decoding — stage 4
model.generate → GenerationMixin_Instruct (utils/generation_utils.py)

# per utterance (batch = 1), greedy, use_cache=True
1  encoder_outputs = encoder(input_values, mask=1s)
2  input_ids = [BOS]            # decoder_start
   if instruct: input_ids += prompt_ids
3  PREFILL: decoder forward
     · finds <bos_speech>/<eos_speech> adjacent
       → inserts speech embeddings (×S)
     · KV-cache now holds  text+S  positions
4  LOOP until EOS or max_length=150:
     logits[:, −1] → argmax → next token
     decoder forward(1 token, cache)
       # len(seq)==1 → no re-insertion
5  decode text; keep <sc> etc.; strip other
   specials (skip_special_tokens regex)
6  write <set>_label.text / _decod.text
   → utils/compute-wer.py

Requires transformers==4.53.x: with ≤4.49 HF’s own GenerationMixin shadows this mix-in in the MRO and generation breaks (ISSUE-05).

CTC decoding — stage 5
model.generate_ctc → forward_ctc (requires talker_ctc=true)

1  encoder_outputs = encoder(input_values)
2  sep_i = separator(pre-adapter states)   # i=1…N
3  for each head i:
     ids = argmax(ctc_lo_i(sep_i))         # (B, T)
     collapse duplicates, remove blank(=V)
4  transcription = concat over heads
   # speaker order = head order (fixed)
5  decode + score like the AED path
   # labels additionally strip the prompt text

Multi-GPU inference — stage 6
inference_asr_gpus.py

setup_distributed()          # BEFORE model.to —
model.to(cuda:local_rank)    # ISSUE-03 fix
dataset.shard(world_size, rank, contiguous)
per-rank loop = AED/CTC decode (left column)
→ per-rank files → barrier → rank0 merges

5 · Pipeline stages (run.sh) and artifacts

stage 1  utils/generate_dataset.py     wav.scp/text → DatasetDict           → datasets/<corpus>
stage 2  utils/create_from_pretrained  wavlm-large ⊕ LLaMA, +special tokens,
                                       resize embeddings                    → dump/<enc>-<dec>
stage 3  finetune_asr.py (DDP, all GPUs)  train (§3)                        → <output_dir>/
           output_dir is DERIVED from the flags:
           mode_<train_mode>-<enc>-<dec>[-encoder_freeze…][-ctc][-refine]
           [-cross_attention_<type>_<feat>][-rmax…][-<bridge>]-<corpus>
           ⇒ stages 4/5/6 MUST be called with the same flags
stage 4  inference_asr.py (1 GPU)      attention decoding + WER             → <set>_decod.wer
stage 5  inference_asr.py              CTC decoding (--ctc_decoding=true)
stage 6  inference_asr_gpus.py (DDP)   sharded decoding / pseudo-labels
