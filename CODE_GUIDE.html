Multi-talker ASR with LLMs

Code walkthrough & hyper-parameter guide for the v1.0 branch. Generated from the source on 2026-05-14.

1. High-level Picture

This repo fine-tunes a Speech-Encoder + LLM-Decoder model for multi-talker ASR. The wiring is roughly:

audio ─► Speech Encoder (WavLM/Whisper) ─► Separator ─► Serialized CTC heads (per talker) │ └► acoustic memory (mix / sep) │ ▼ ┌───────────────────────────────────────┐ │ LLaMA Decoder (causal) │ │ │ │ each layer: │ │ self-attn ◄── PEFT LoRA │ ① Self-attn adapter │ │ │ │ ▼ │ │ adaptation_module(...) ◄── Cross │ ② Cross-attn adapter │ │ -attn over │ │ ▼ acoustic memory │ │ MLP │ └───────────────────────────────────────┘ │ ▼ tokens (transcripts of all talkers)

Two LoRA-style adapter groups are stacked inside each Llama decoder layer:

  • Self-attention adapter — vanilla PEFT LoRA on the existing q/k/v/o_proj.
  • Cross-attention adapter — a custom module added between self-attn and MLP that cross-attends from decoder hidden states to acoustic memory; itself contains LoRA on its own q/k/v/out. Several variants exist (tiny, gatetiny, ctcaware, adapgatetiny).

Per-step forward pass (modeling_speech_encoder_decoder_llama.py)

  1. Encoder produces mixed_encoding_feature; separator splits into per-talker hidden states sep_hidden_states.
  2. (optional) CTCAwareFrameRefiner refines those hidden states using the CTC heads.
  3. The cross-attn memory is selected by decoder_cross_attention_feature:
    • "mix" → mixed encoder output
    • "sep" → concatenated per-talker hidden states (mask repeated & aligned)
    …llama.py:603-621
  4. (optional) CTC bridge: when ctc_bridge=True, the encoder hidden states fed to the decoder are replaced by either raw separated features (raw) or CTC-prompt embeddings prepended (ctcprompt). …llama.py:624-661
  5. Decoder is called with acoustic_mem, acoustic_mask, and the cross_att_adap ModuleList passed via adaptation_modules. Inside each LlamaDecoderLayer.forward, after self-attn the corresponding adapter runs: 
    refined = adaptation_module(hidden_states,
                            acoustic_mem,
                            acoustic_sep,
                            mem_mask=acoustic_mask, …)
hidden_states = refined   # no outer layer-gate
    llama_modules.py:383-396
  6. Losses combine CE on labels + (optional) per-talker CTC losses, weighted by ctc_alpha.

3. The Two Adapters Side-by-Side

① Self-attention adapter

file: src/insert_adapter_decoder.py

  • Standard PEFT LoraConfig, attached via model.add_adapter(...) / enable_adapters().
  • Wraps existing decoder self_attn.{k,q,v,o}_proj.
  • Fixed rank r, scale α / r, dropout on the input side.
  • No LayerNorm, no gating — pure additive ΔW = B·A.
  • Only the LoRA A/B added by PEFT are trainable in the self-attn path.
LoraConfig(
  r=selfattn_lora_r,
  lora_alpha=selfattn_lora_alpha,
  lora_dropout=selfattn_lora_dropout,
  target_modules=[decoder…self_attn.{k,q,v,o}_proj],
)

② Cross-attention adapter

file: models/adap_gate_tiny_crossatt_module.py (and 3 simpler siblings)

  • Custom nn.Module — adds an entirely new cross-attention block (its own q_proj / k_proj / v_proj / out_proj) on top of the frozen base.
  • Q from decoder hidden state, K/V from acoustic memory (mem_dim ≠ hidden_size).
  • LoRA is applied to those new projections, with adaptive per-rank gates (sigmoid(rank_logits)) — supports budget & pruning (rank_usage(), prune_lora_ranks()).
  • Has ln_in / ln_out and a scalar layer gate gate_logit (init sigmoid(-2)≈0.12).
  • Inserted manually in LlamaDecoderLayer.forward — not via PEFT.
out = hidden + sigmoid(gate_logit) *
              ( LayerNorm(hidden + out_proj(attn(Q, K, V))) - hidden )

Variants of the cross-attention adapter (selected by decoder_cross_attention_type)

typeclassextras vs. tiny
tinyTinyCrossAttnAdapterbaseline — full-rank q/k/v/out, no gate, no LoRA.
gatetinyGatedTinyCrossAttnAdapter+ scalar gate on residual.

4. Hyper-parameters and What They Do

Every flag below comes from src/arguments.py (CLI / JSON config). Below each table I describe what happens at the code level when you change it.

4.1 Architecture toggles

flagdefaulteffect
model_name_or_path— Path/identifier passed to SpeechEncoderDecoderModelLlama.from_pretrained. Determines encoder + decoder backbones.
talker_ctcFalse If True → build Separator + a serialized_ctc[talker_numbers] ModuleList; per-talker CTC loss participates in training. If False, no separator is constructed and the CTC branch is empty.
talker_ctc_refineFalse Adds a CTCAwareFrameRefiner that uses CTC heads to refine the per-talker hidden states before passing them downstream.
talker_numbers2 Number of speakers. Controls (i) separator output heads, (ii) length of serialized_ctc, (iii) repeat-factor of encoder_attention_mask when concatenating per-talker features, (iv) label split.
separator_hidden896 Hidden width of the Separator. Pure capacity knob — bigger = more separator params.
ctc_bridgeFalse If True the encoder→decoder feature is replaced with a CTC-derived bridge (see ctc_bridge_type).
ctc_bridge_type"raw" raw: concat per-talker hidden states and pass through encoder adapter + projection. ctcprompt: build prefix embeddings from CTC argmax transcripts and prepend them to the encoder hidden states.
decoder_cross_attentionFalse Master switch for the cross-attention adapter. If False, cross_att_adap=None and the decoder layer skips the adaptation_module block.
decoder_cross_attention_type"tiny" Selects which of the four adapter classes to instantiate per decoder layer (see table in §3).
decoder_cross_attention_feature"raw" Choose memory: "mix" → mixed encoder output; "sep" → concatenated per-talker hidden states.

4.2 LoRA — self-attention path (PEFT)

flagdefaulteffect
adapter_only_decoderTrue True → PEFT target_modules lists only the decoder layers’ self_attn.{k,q,v,o}_proj. False → glob targets "k_proj","q_proj","v_proj","o_proj" — PEFT will inject LoRA into every module that matches those names (including the encoder if applicable).
selfattn_lora_r16 LoRA rank for self-attn. ΔW = B(d,r)·A(r,d). Larger r → more capacity & params; trainable count scales linearly with r.
selfattn_lora_alpha32 Effective scale = alpha / r. Increasing α makes the adapter contribute more strongly to the output without changing parameter count.
selfattn_lora_dropout0.1 Dropout on the LoRA input before the down-projection A. Regularizes the adapter; 0 disables.

4.3 LoRA — cross-attention path (custom adapter)

flagdefaulteffect
r_max16 Maximum LoRA rank inside each q/k/v/out branch of the cross-attn adapter. Each rank carries an independent learnable gate sigmoid(rank_logits); truly active rank is data-driven, capped at r_max.
lora_alpha16 Static scale: lora_scale = lora_alpha / r_max. Note: when pruning, r_max shrinks and lora_scale is recomputed.
(hard-coded) lora_dropout=0.05— Dropout on the LoRA input (set in modeling_speech_encoder_decoder_llama.py:239).
(hard-coded) init_rank_logit=2.0— Initial value of every rank logit. sigmoid(2)≈0.88 — adapters start mostly "on" and are expected to be pruned by budget pressure during training.
(hard-coded) apply_lora_to="qkv_out"— Apply LoRA to Q, K, V, and Out (alternative: "q_out" applies only to Q and Out — K/V are then pure base projections).
(hard-coded) freeze_base=True— Freeze the base q/k/v/out_proj of the cross-attn adapter, so only the LoRA branches, LayerNorms, and the scalar gate are trainable.
(learned) gate_logitinit −2 Scalar that controls how much of the cross-attn delta is mixed into the residual (sigmoid(−2)≈0.12). Trained jointly.
Key contrast. selfattn_lora_* are PEFT-side knobs (vanilla LoRA, fixed rank, simple α/r scale). r_max / lora_alpha live on the cross-attn side, where the LoRA is custom and supports per-rank gating, soft rank usage, and physical pruning via prune_lora_ranks().

5. How a Few Knobs Interact

Turning on the cross-attn adapter end-to-end

decoder_cross_attention=true
decoder_cross_attention_type=adapgatetiny    # picks AdapGatedTinyCrossAttnAdapter
decoder_cross_attention_feature=sep          # use concatenated per-talker features as memory
r_max=32
lora_alpha=16

Effect: one AdapGatedTinyCrossAttnAdapter is built per decoder layer with per-branch LoRA up to rank 32 and scale 16/32; the memory it cross-attends to is the concatenation of separated talker features. The scalar gate starts low so the adapter does almost nothing at step 0 and ramps up.

Self-attn LoRA only, no cross-attn

decoder_cross_attention=false
adapter_only_decoder=true
selfattn_lora_r=16
selfattn_lora_alpha=32
selfattn_lora_dropout=0.1

Effect: insert_adapters builds a LoraConfig whose target_modules lists every decoder.model.layers.N.self_attn.{k,q,v,o}_proj; PEFT adds the A/B matrices. The cross-attn block in the decoder layer is a no-op.

CTC-only pre-training

train_mode=ctc
talker_ctc=true
talker_numbers=2
adapter_only_decoder=false   # no PEFT adapter inserted in this branch anyway

Effect: everything freezes, then unfreeze_selected_params reopens the CTC heads and separator (partial_others_unfreeze includes "ctc"). No LoRA, no cross-attn — useful to warm up the separator + CTC heads before plugging the LLM decoder back in.
